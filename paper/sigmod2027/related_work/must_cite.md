# Must-Cite List

This is the strict first-pass related-work set for the SIGMOD/PACMMOD 2027 submission.

- Belady 1966: `belady1966study`
- LIRS: `jiang2002lirs`
- ARC: `megiddo2003arc`
- CLOCK-Pro: `jiang2005clockpro`
- GreedyDual-Size / cost-aware caching: `cao1997greedydual`
- TinyLFU: `einziger2017tinylfu`
- W-TinyLFU / adaptive software cache management: `einziger2018wtinylfu`
