\section{Release Construction and Validation}
\label{sec:release-validation}

The release pipeline is designed to package existing generated candidate rows into a benchmark artifact without requiring raw traces in the release package. The builder uses an out-of-core DuckDB path to ingest candidate shards, normalize split values, emit partitioned Parquet candidate rows, derive the decision view, optionally create a capped pairwise sample, and write release metadata and checksums.

The validation surface is part of the benchmark contribution: reproducible scripts verify candidate-partition schema completeness, split-set consistency, family inclusion/exclusion, within-decision duplicate and metadata consistency, decision-view schema/count consistency, and checksum integrity.

\begin{sloppypar}
The evaluated release package passed this full validation suite via those reproducible scripts, independent of unpublished hosting details and superseded internal status notes; this validates the release package's construction, not final public hosting or DOI completeness.
\end{sloppypar}

\subsection{Provenance of the evaluation results in this paper}

Beyond the released dataset above, every result reported in
Sections~\ref{sec:characterization}--\ref{sec:continuation} traces to an
independently validated analysis record. These records cover target
discriminativeness, Tier-1 closed-loop behavior,
offline$\leftrightarrow$closed-loop linkage, mechanistic workload
analysis, sampled continuation sensitivity, and the full-population MRU
continuation census. Each record includes reproducible scripts and, where
applicable, an independent recomputation of headline values. The manuscript
reports only results whose validation and recheck steps completed.

\textbf{Two label sources must not be conflated:} released labels use
canonical LRU continuation (Section~\ref{sec:label-generation}); the
MRU/random \emph{relabelings} used for the sensitivity study
(Section~\ref{sec:continuation}) are diagnostic only, not an alternative
release.

\textbf{The population-scale MRU continuation census is complete
evidence.} The census covers all 2{,}363{,}286 decision-horizon records in
the evaluated corpus and passed an independent recheck before its summaries
were imported into this manuscript. The raw 1.6 GB census output is
preserved separately; the manuscript uses only compact summaries,
validation reports, manifests, and Figure~\ref{fig:continuation-robustness}
source data.

\textbf{A known, unresolved provenance limitation:} the exact historical
commit provenance of the full-release label generator is incomplete. This
does not affect the validity of the validated analyses above, each of
which independently records its own generation context, but it means the
full historical lineage of the generator code itself is not completely
reconstructable from repository history alone.
