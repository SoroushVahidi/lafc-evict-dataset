# Publication Tooling

This directory contains templates and helpers for preparing LAFC-Evict publication metadata.

- All publication scripts are **dry-run by default**.
- Hugging Face is intended for hosting dataset artifacts.
- Zenodo is intended for DOI and archive metadata.
- GitHub Releases are intended for code release notes and small metadata assets, not the main large dataset payload.

The synthetic sample release is only a workflow test. The real `lafc-evict-v0.1-open` release should only be uploaded after release validation and license-scope checks are complete.
