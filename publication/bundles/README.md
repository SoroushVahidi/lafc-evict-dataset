# Publication Bundles

This directory contains small, reviewable publication artifacts.

- Dataset release bundles belong under a release-specific `lafc-evict-*`
  directory and must not be confused with the large ignored `release/` trees.
- `sigmod2027_anonymous_review/` and its archive are manuscript review
  artifacts. They are not LAFC-Evict dataset payloads and are intentionally
  kept separate from the v0.2 HF and Zenodo release records.

The current authoritative publication state is recorded in
`publication/LAFC_EVICT_PUBLICATION_STATE.json`.
