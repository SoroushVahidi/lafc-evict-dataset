# Internal Job Logs

Raw HPC job-submission notes (Slurm commands, queue states, node names,
scratch/home paths, usernames). These are internal provenance records for
the maintainers and are not part of any SIGMOD/PACMMOD submission or review
artifact.

Do not copy this directory into `paper/sigmod2027/` or into any anonymous
submission bundle. The scientific results these jobs produced are already
captured, in review-safe form, under `paper/sigmod2027/results/`.
